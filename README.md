## Dokumentasi Kegiatan Workshop Day-1
### 1. Rangkuman Materi
Workshop hari pertama ini membahas dua topik utama, yaitu pemanfaatan kecerdasan buatan (Artificial Intelligence) melalui teknik perancangan instruksi (prompt engineering) serta manajemen perubahan dan kolaborasi menggunakan Version Control System Git dan platform GitHub. Pemateri menjelaskan dasar-dasar penyusunan prompt yang efektif menggunakan struktur yang baik seperti peran (role), tugas (task), konteks (context), dan format (format) guna menghasilkan keluaran kode atau teks yang akurat. Selain itu, peserta dipandu memahami konsep dasar sistem version control Git—mulai dari working directory, staging area, hingga repository—serta cara menghubungkannya ke GitHub menggunakan kunci SSH dan perintah esensial seperti git init, git add, git commit, git push, dan git pull.

### 2. Poin-Poin Penting / Pengetahuan Baru
- Penggunaan struktur prompt yang spesifik (mencakup Role, Task, Context, dan Format) dapat meningkatkan performa AI serta menghasilkan respon yang lebih terarah dan berkualitas.

- Perbedaan mendasar antara Git dan GitHub, di mana Git adalah sistem version control terdistribusi (DVCS) lokal, sedangkan GitHub adalah platform berbasis web untuk menyimpan repository secara online dan mendukung kolaborasi.

- Alur kerja lokal Git bergerak dari Working Directory ke Staging Area sebelum akhirnya disimpan permanen ke dalam Git Directory (Repository) melalui perintah commit.

- Penggunaan SSH key dengan algoritma Ed25519 dan integrasinya ke dalam SSH agent serta macOS Keychain untuk autentikasi yang aman saat terhubung ke GitHub.

- Praktik langsung pembuatan aplikasi sederhana berupa Student Task Planner menggunakan bantuan AI, yang kemudian dikelola versinya menggunakan Git dan diunggah ke GitHub.

### 3. Pendapat Pribadi
Workshop hari pertama ini sangat menarik dan aplikatif, terutama karena materi langsung menjembatani teori dengan kebutuhan nyata di industri modern. Kombinasi antara cara memanfaatkan AI secara optimal melalui prompt engineering dan pemahaman tentang version control menggunakan Git/GitHub merupakan keterampilan esensial yang sangat membantu developer maupun product designer dalam mengelola proyek secara kolaboratif dan efisien.
