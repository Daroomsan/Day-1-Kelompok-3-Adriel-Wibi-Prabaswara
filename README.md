## Dokumentasi Kegiatan Workshop Day-1
### 1. Rangkuman Materi
Workshop membahas dua topik utama, yaitu pemanfaatan kecerdasan buatan (Artificial Intelligence) melalui perancangan instruksi (prompt engineering) serta manajemen perubahan dan kolaborasi menggunakan Version Control System Git dan platform GitHub. Dasar-dasar penyusunan prompt yang efektif menggunakan struktur yang baik seperti (role), tugas (task), konteks (context), dan format (format) untuk menghasilkan keluaran kode yang akurat. Selain itu, dijelaskan juga konsep dasar sistem  version control Git mulai dari working directory, staging area, hingga repository, serta cara menghubungkannya ke GitHub menggunakan kunci SSH dan perintah esensial seperti git init, git add, git commit, git push, dan git pull.

### 2. Poin-Poin Penting / Pengetahuan Baru
- Penggunaan struktur prompt yang spesifik (seperti Role, Task, Context, dan Format) dapat meningkatkan jawaban AI agar lebih relevan dengan printah prompt

- Perbedaan mendasar antara Git dan GitHub, di mana Git adalah sistem version control terdistribusi (DVCS), sedangkan GitHub adalah platform berbasis web untuk menyimpan repository secara online.

- Penggunaan SSH key dengan algoritma Ed25519 dan integrasinya ke dalam SSH agent serta macOS Keychain untuk autentikasi yang aman saat terhubung ke GitHub.
